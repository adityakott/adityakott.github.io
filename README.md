# Aditya Kottapalli — Academic Website

A responsive, static academic homepage built with HTML, CSS and JavaScript. It is designed for deployment with GitHub Pages.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment and visit `https://YOUR-GITHUB-USERNAME.github.io`.

## Before publishing, personalize these items
- Replace `YOUR_EMAIL@example.com` with your professional email.
- Replace the Google Scholar, ORCID, LinkedIn and GitHub placeholder URLs.
- Verify the publication year, author list and DOI for the npj Climate and Atmospheric Science paper.
- Add the titles, author lists, journal details and DOI links for the two Climate Dynamics papers.
- Add your portrait and CV PDF if desired.
- Check the academic appointment dates and wording.

No build tools or paid hosting are required. Google Fonts is an optional external font dependency; the page has fallback fonts.
